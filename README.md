## ✨ Sobre o projeto

O **MasterBIT** é um catálogo web de cartas Pokémon TCG, feito para quem quer explorar coleções e descobrir mais sobre cada carta. A interface responsiva combina referências de pixel art com uma experiência simples de navegação.

### O que você encontra

- Catálogo de coleções e cartas Pokémon TCG.
- Pesquisa de cartas e consulta de imagens e raridades.
- Preços de referência em dólar e conversão estimada para reais.
- Interface responsiva com visual inspirado em jogos retrô.

## 🛠️ Tecnologias

- **Frontend:** HTML, CSS e JavaScript.
- **Backend:** Python e FastAPI.
- **Hospedagem:** Vercel.
- **Dados:** APIs externas e arquivos locais de coleções.


> Os preços são valores de referência. A conversão para reais é uma estimativa e pode variar conforme a cotação e a fonte dos dados.
